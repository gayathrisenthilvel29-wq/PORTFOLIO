Pocket e-paper reader

The idea

An open-source, pocket-sized reading device. A 4.2-inch e-paper screen is easy on the eyes and sips power, and touch gestures turn the pages.

Hardware plan

  • ESP32-S3 microcontroller
  • 4.2-inch e-paper display
  • Touch input for navigation

Intended features

  • Touch navigation: turn pages and open menus
  • Wi-Fi document transfer, so files reach the reader without cables
  • Open-source hardware and software

Where it stands

In development, not a finished product. Photos, schematics and code will be added here once there is real progress to show.
